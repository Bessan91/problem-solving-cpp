# Task 2: Problem Solving with C++

Welcome to the second task repository! This project contains a collection of solutions to various programming problems, focusing on practical implementation and building a solid foundation in software logic.

##  Focus Areas
In this task, I focused heavily on mastering core control flow structures and logical operations, specifically:
* **`if` statements** (Conditional logic, nested conditions, and decision making).
* **`while` loops** (Repetitive logic, iterations, and loop control statements).

## Solved Problems & Examples
This task includes multiple practical examples designed to strengthen problem-solving skills, including:
* **Basic Mathematical Logic:** Programs to check numbers (even/odd, positive/negative/zero).
* **User Input Validation:** Utilizing `while` loops to ensure correct input from the user before proceeding.
* **Repetitive Calculations:** Finding sums, averages, or factorials within a specific range using iteration.
* **Nested Logic:** Combining `if` conditions inside `while` loops to solve more complex scenarios.

##  Tools & Technologies Used
* **Language:** C++
* **Concepts:** Control Flow, Conditional Statements, Iteration, Logic Building.
